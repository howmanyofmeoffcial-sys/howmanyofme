# Indexability & Quality Gates

## 1. Indexable vs Non-Indexable URL Rules

Every route generated by HowManyOfMe.co adheres to strict indexability criteria:

| Route Type | Robots Header | Sitemap Inclusion | Quality Gate |
| :--- | :--- | :--- | :--- |
| **Pillar & Static Pages** (`/`, `/about`, `/tools/*`, `/data`, `/research/*`) | `index, follow` | Yes (Priority 0.8–1.0) | Pass |
| **First-Name Profiles** (`/name/*`) | `index, follow` | Yes (Priority 0.7) | Valid SSA data |
| **Full-Name Profiles** (`/people/*`) | `index, follow` | Yes (Priority 0.6) | Valid joint model |
| **Surname Profiles** (`/last-name/*`) | `index, follow` | Yes (Priority 0.7) | Top Census rank |
| **Name Comparisons** (`/name-comparison/*`) | `index, follow` | Yes (Priority 0.7) | Verified pair |
| **Embed Iframe Badges** (`/embed/*`) | `noindex, nofollow` | Excluded from Sitemap | Utility endpoint |
| **404 / Error Pages** | `noindex, follow` | Excluded from Sitemap | N/A |

---

## 2. Canonical Tag Enforcement

1. Every indexable page MUST emit an explicit, absolute `<link rel="canonical" href="https://howmanyofme.co/..." />`.
2. Canonical tags must NEVER contain query parameters or trailing slashes.
3. `scripts/validate-url-parity.mjs` verifies that 100% of HTML files in `dist/` match their expected canonical tag with zero mismatches.
