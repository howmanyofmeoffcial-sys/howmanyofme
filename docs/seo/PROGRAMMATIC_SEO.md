# Programmatic SEO Engine

## 1. Quality-Gated Programmatic Expansion

HowManyOfMe.co utilizes programmatic page generation strictly where:
1. **Official, verified government data exists** (SSA 1880–2024, Census 2020).
2. **Explicit search demand is proven** via GSC or SERP keyword research.
3. **Intent is distinct** and does not cannibalize existing canonical routes.
4. **Value is substantive** (rich charts, actuarial estimates, provenance), never thin or templated boilerplate.

---

## 2. Active Programmatic Families

| Family | Pattern | Route Count | Quality Gate |
| :--- | :--- | :--- | :--- |
| **First-Name Profiles** | `/name/[name]` | `583` | Minimum 100+ historical SSA occurrences |
| **Similar Names** | `/similar-names/[name]` | `583` | Minimum 3 algorithmic matches |
| **Full-Name Profiles** | `/people/[first-last]` | `700` | Joint statistical confidence model |
| **Surname Profiles** | `/last-name/[surname]` | `50` | Top 50 Decennial Census surnames |
| **Name Comparisons** | `/name-comparison/[nameA]-vs-[nameB]` | `20` | High-volume head-to-head pairs |

---

## 3. Expansion Gating Protocol

Before adding any new programmatic vertical:
1. Complete candidate discovery & search demand evaluation.
2. Verify mathematical data provenance from official registries.
3. Launch a **controlled pilot cohort (20–50 URLs)**.
4. Measure indexing velocity, organic impressions, and bounce rates for 30 days before scaling.
